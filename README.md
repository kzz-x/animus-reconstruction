# Animus Reconstruction｜数字世界重建器

一个独立、可复用的 Three.js **三维场景重建转场预设**：从白色数字虚空开始，以指定位置为原点，波前在世界空间传播，场景经历 **点云/网格 → 几何白模 → 碎片翻转拼合 → 真实材质恢复**，最终完整呈现导入场景。

> 灵感来自《刺客信条》的 Animus / Memory Corridor 数字记忆重建语言。本项目是独立创作的通用动画工具，不包含游戏素材，也不与游戏发行商关联。

## 目标体验

1. 上传完整 GLB / GLTF 场景，或把引擎接入已有 Three.js `Object3D`。
2. 在视口中点击选取重建原点；一键应用四类预设：经典 Animus、线框构建、像素翻转、扫描重建。
3. 通过中文控件调整波前、碎片、白模、材质、摄影机；拖动时间轴精确预览。
4. 最后帧回到场景**原始材质、层级和外观**；可以保存预设与项目、导出视频/帧序列。

**视觉要求：**看到的是三维世界从无到有地被构建，而不是一张二维遮罩划过，也不是单纯 dissolve。

## 现在有什么

当前仓库为 **Codex 开发起点（P0 基座）**：包含项目规范、阶段验收标准、Three.js 实时场景查看器、内置测试场景、GLB 导入、选择重建原点。重建 Shader、碎片、动画时间轴、视频输出待按里程碑开发，不应将基座当作成品。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的地址。拖入 `.glb`，或点击「选择 GLB」。在视口中 **Shift + 单击** 设定重建原点；鼠标拖拽旋转，滚轮缩放。

## 产品原则

**最终画面质量 > 操作易用性 > 兼容性覆盖 > 代码形式。** 首先做出精致的 Animus 式重建效果，再扩展模式。源代码可以模块化，发布版本是可本地运行的 HTML/Web 应用；保留可嵌入其他 Three.js 工程的独立引擎入口。
