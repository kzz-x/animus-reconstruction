# Animus Reconstruction｜数字世界重建器

我想做一个**能给任何三维场景套用的数字世界重建转场**。视觉灵感来自《刺客信条》Animus：整个世界从空白虚空中，以人物或指定位置为中心，一点点被数字化地构建出来。

这不是一次性的演示镜头，而是以后导入不同建筑、室内、城市、工业设备、主板、手机内部结构，都可以直接使用的**高质量动画预设 / 创作工具**。

## 我想看到的画面

最开始，人物或指定主体站在近乎无边界的白色空间里。地面以他为中心向外生成；远处的建筑、物体和环境跟着逐渐出现。空间不是简单淡入：细密的像素片、三角碎片、网格和局部白模在空中翻转、聚集、拼合，像实时加载几何体；重建波前掠过时，完整材质、光照和场景细节逐渐恢复，最后留下一个真实、完整、可继续运镜的三维世界。

**最重要的是“一个完整三维世界正在被数字化组装”，而不是普通溶解、淡入或一层屏幕特效。** 画面应该有明确的空间感、节奏、精细度和影视级完成度。

## 我想怎么使用

- 导入一个完整三维场景，选一个重建起点，就能看到这个转场。
- 有几套风格不同的预设，也能自由调整重建节奏、形态、强度、颜色和细节。
- 可以通过可视化控件调整并预览动画、摄影机运动，保存自己的预设，输出视频或帧序列。
- 尽可能兼容有复杂层级、材质和多个物体的场景；重建结束时保留原场景的真实外观。
- 希望它既能独立使用，也方便融入其他三维创作项目。

画面与操作目标见 [docs/PRODUCT.md](docs/PRODUCT.md)，少量检索线索见 [docs/REFERENCES.md](docs/REFERENCES.md)。

## 给开发者 / Codex

**这是创作目标，不是指定实现方案。** 请根据最终画面和体验，自主选择技术、架构、开发顺序以及更好的创意方案。仓库里的现有 Three.js 预览代码只是早期临时示例，完全可以重写，不需要沿用它的结构。

当前示例如需运行：`npm install && npm run dev`。

## 可交互概念验证（已提交）

[打开汽车 + 街区世界重建 Demo 源文件](./demos/animus-car-city-demo.html)。这是无需构建的独立 HTML 文件，下载后直接用支持 WebGL 的浏览器打开即可。可旋转视角、切换四个初步风格、拖动扫描进度及调整部分参数。

**现状：**已验证从汽车中心向外的空间重建、数字碎片和完整场景过渡，但模型、灯光、真实反射、碎片材质、复杂场景导入仍有显著提升空间。它只是验证方向的样片，不是需要维持的最终架构。

**当前视觉与交互目标**在 [docs/PRODUCT.md](./docs/PRODUCT.md) 中，重点新增真实资产、光影和材质品质，碎片形状/运动/材质的可视化控制，摄影机与多轨时间轴，以及八类可组合预设。由开发者自主选择实现方式。
