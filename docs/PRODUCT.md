# 想要的视觉与体验

## 视觉核心

参考《刺客信条》Animus 的记忆场景载入：**一片空白虚空，以人物或指定坐标为中心，整个三维世界逐步被数字化重建出来。**

希望画面里能感受到这些细节：

- 从脚下向外扩散的重建过程，地面、墙体、建筑和远景像被实时生成；可以有从底部向上攀升的层次。
- 细密的像素方片、三角几何碎片翻转、流动、定位和拼合；伴随若隐若现的点云、网格、线框、白模和局部数字故障。
- 已经形成的物体继续从数字几何变成带有真实材质、光照和阴影的实体；扫描前沿带有精致的变化和节奏。
- 最终完整恢复导入的真实场景，镜头可以继续推进、转动或探索。

这些元素是**想要的视觉感受，不是规定必须逐项使用的技术步骤**。可以大胆寻找更高级、更有设计感的表现。尤其希望保留那种“空间里真的正在构造三维物体”的观感，而非普通屏幕遮罩、透明度变化或廉价粒子闪烁。

## 风格灵感

可以从以下方向发挥、组合、改编，不必限定成四套孤立的实现：

- **经典 Animus**：白色数字虚空、由近至远的历史世界生成、轻微蓝白数字扫描。
- **Wireframe Build**：点云 / 技术线框 / 白模与真实实体交织，适合工业科普。
- **Voxel Flip**：密集方片、三角碎片翻转吸附，几何建造感更强。
- **Scan Reveal**：一道富有层次的空间构建波划过大型场景，适合快速转场。

## 使用场景与体验

例如：导入一个完整的极客桌面、数据中心、城市街道或手机拆解模型，用户只需要设定重建起点、挑选预设并调整动画，即可做出一个有质感的镜头。

希望有**中文、直观、可视化**的控制界面：导入场景、选择对象与起点、调整风格与动画、拖动进度预览、设计运镜、保存配置、录制或输出素材。日后换模型也能复用，不需要每次重新开发特效。

## 什么样的结果才算好

**画面：**从空白到实体的过程具有真实的三维空间层次，几何构建细节丰富，重建节奏自然且有冲击力，最终画面能达到高完成度 Motion Design 的质感。

**复用：**不局限于内置演示物体。复杂多物体场景中也能清楚看到构建过程，旋转摄影机后效果依然与三维世界一致。

**保真：**结束时原场景的结构和材质得到保留；任意时间点的预览与导出结果稳定。

**体验：**能以预设为起点快速做出成片，再按需要细调。为了更好的视觉效果和更顺手的使用体验，可以自主改良这里没有想到的细节。

具体技术方案和开发计划由开发者决定。

## 进一步的画面目标：从概念验证到成片质感

现有 [汽车与街区 Demo](../demos/animus-car-city-demo.html) 已验证基本动效方向：由中心向外扩散、碎片伴随重建、物体最后恢复为实体。但它还只是**低精度程序模型 + 初步光影的视觉证明**，请不要把它当成画面质量上限。

下一版最值得追求的是**画面材质与摄影感**：

- **真实主体与环境**：优先使用有可信比例、曲面、车灯玻璃、轮毂、建筑立面与路面细节的真实模型。让用户导入自己的完整场景；内置示例也要足够体现效果，不局限于积木房屋。
- **高级真实光影**：车漆的清漆层反射、金属边缘高光、玻璃透光与反射、地面接触阴影、细腻反射环境、电影级明暗对比。灯光、反射与色彩要统一，而不是靠普遍加 Bloom 冒充质感。
- **真实的碎片物质感**：碎片有清晰的形状和厚度、材质、受光面、反射高光、旋转中明暗变化、空间遮挡与局部景深，体积、密度和速度富于节奏；它们看起来是正在拼合物体的数字几何，而非一群扁平发光点。
- **有审美的动效**：先有空间布局与光的叙事，再有数字重建波；轮廓和重点材质要在适当时刻被看见。允许不完全对称、强烈近景与摄影机绕行，避免网页技术演示感。
- **素材优先**：可搜索并使用授权清晰的优质模型、HDRI 和贴图；最适合验证材质的车模、环境资产可替换，并能展示「原始完整场景」与「过渡中」的效果对比。

## 理想工作台与交互

希望打开后感觉像一个**专门制作三维重建镜头的轻量创作软件**，而不是一页塞满参数的 Shader 调试面板。

- **顶部**：项目名、撤销/重做、保存项目、预设保存、预览/成品画质、A/B 效果对比。
- **左侧**：资产导入与场景树。可以选中物体、分组、隐藏、排除重建、指定主体或重建起点；也可查看材质。
- **中央**：大面积三维实时视口。支持轨道查看、选择/变换重建原点、灯光与摄影机操作手柄；可选显示网格、扫描边界、焦点、景深与构图参考。
- **右侧**：预设缩略图、最常用的几个调节项，以及按类别折叠的中文参数。高频项直接调，次要项放进高级设置；参数应支持重置、数值精调、复制与可关键帧化。
- **底部**：播放、逐帧、循环、总时长、进度拖动与动画轨道。可以分别编辑重建传播、碎片强度、材质变化、摄影机和灯光的出场节奏；尽量直观、易拖动。
- **体验**：改参数立即看到效果；切换预设保留场景与摄影机；提供清晰的默认值、撤销、可复现的随机种子、保存自己的风格组合。支持横版与竖版构图。

### 常用控件（按用户理解方式组织）

| 分类 | 希望可直接调整的内容 |
| --- | --- |
| **重建范围与顺序** | 点击选择中心、自由 XYZ、跟随主体；水平径向/球形/方向扫描；范围、宽度、速度、扩散曲线、先地面后建筑/逐层爬升、随机扰动、物体先后、排除对象 |

| **碎片运动** | 数量密度、大小与随机大小范围、厚度、翻转角度/方向/轴、翻转速度、散开半径、飞入/吸附距离、旋转随机度、出现时长、尾迹、扰动、聚合缓动 |
| **碎片材质** | 沿用原场景材质 / 白色陶瓷 / 金属 / 玻璃 / 发光数字材质；金属度、粗糙度、透射/不透明度、清漆感、折射、反射强度、边缘微光 |

| **时间与输出** | 总时长、重建起止、片段重叠与节奏、播放方向、反向解构、预览质量、分辨率/FPS、录制视频、透明背景或 PNG 帧序列、预设与工程保存 |

**交互优先级**：默认只露出常用项（风格、进度、速度、碎片形状/大小/密度、HDRI、主光方向、景深、摄影机），其余按折叠组展开。更专业的用户可以进行对象级覆盖与动画关键帧编辑。

## 预设库的视觉方向

预设应该是**有完整艺术指导的灯光、材质、碎片形态与时间节奏组合**，不只是更换一个颜色或 Shader 开关。建议先让这八类有明显差异，并允许自由混搭、保存为自定义预设：

| 预设名称 | 希望呈现的画面气质 |
| --- | --- |
| **01 Animus Memory / 记忆重建** | 无垠白色虚空，蓝白细碎几何与白模从主体脚下向外重建，最后还原真实世界，克制、精确、带神秘感 |
| **02 Cinematic Assembly / 电影级拼装** | 深色虚拟影棚，高品质金属/玻璃碎片在明暗强烈的灯光下翻转吸附，强调高级产品广告级反射与体积 |
| **03 Technical Blueprint / 工业蓝图** | 暖白/深蓝背景、极细线框、测量式网格和技术白模逐渐转换成实体，适合硬件科普 |
| **04 Voxel Mosaic / 像素马赛克** | 大小不一的方片和六角片清晰翻转、错位、渐次归位，偏图形设计与强节奏 |
| **05 Glass Data / 光学玻璃数据** | 半透明、清澈折射的微型玻璃片和细微高光，像玻璃晶体逐层长成真实场景 |
| **06 Signal Glitch / 信号故障** | 不稳定的数字数据重构，分区错位、扫描重复、局部噪声和闪断后快速稳定，精致而非普通老式电视故障 |
| **07 Material Sync / 材质同步** | 精确的几何/白模结构先建好，然后真实材质和光影沿物体表面快速恢复，适合技术解构转产品成品 |
| **08 Reverse Collapse / 逆向解构** | 已建成的真实世界向起点有秩序地碎裂、翻转、散成线框/数据，并消隐到虚空 |

预设里还有可复用的**碎片材质子预设**（镜面金属、磨砂陶瓷、低折射玻璃、液态玻璃感、虹彩薄膜、哑光图形片、细微自发光）；**灯光子预设**（柔和摄影棚、侧逆光、强轮廓、低照度城市夜景、自然天光）；**摄影机预设**（跟随扫描波、宏观全景→局部特写、绕行揭示、定镜聚焦）。

## 最近一次试验的结论与下一步重点

**已经验证视觉方向**：汽车中心扩散、周围街道建筑由数字碎片与白模呈现再变成完整场景，可播放并改变视角。**尚未验证**真实模型、复杂 PBR 材质和真实高质量反射，以及任意导入场景的泛化程度。

当前最值得优先改进的是**真实模型与环境、摄影级光影、具有厚度与反射的碎片**，并让用户直接选形状、材质、光源位置、摄影机和节奏。具体如何安排开发、使用什么渲染技术以及需要多少阶段，由开发者自主决定。
