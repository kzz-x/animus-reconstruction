# 想要的视觉与体验

## 视觉核心

参考《刺客信条》Animus 的记忆场景载入：**一片空白虚空，以人物或指定坐标为中心，整个三维世界逐步被数字化重建出来。**

希望画面里能感受到这些细节：

- 从脚下向外扩散的重建过程，地面、墙体、建筑和远景像被实时生成；可以有从底部向上攀升的层次。
- 细密的像素方片、三角几何碎片翻转、流动、定位和拼合；伴随若隐若现的点云、网格、线框、白模和局部数字故障。
- 已经形成的物体继续从数字几何变成带有真实材质、光照和阴影的实体；扫描前沿带有精致的变化和节奏。
- 最终完整恢复导入的真实场景，镜头可以继续推进、转动或探索。

这些元素是**想要的视觉感受，不是规定必须逐项使用的技术步骤**。可以大胆寻找更高级、更有设计感的表现。尤其希望保留那种“空间里真的正在构造三维物体”的观感，而非普通屏幕遮罩、透明度变化或廉价粒子闪烁。

## 风格灵感

可以从以下方向发挥、组合、改编，不必限定成四套孤立的实现：

- **经典 Animus**：白色数字虚空、由近至远的历史世界生成、轻微蓝白数字扫描。
- **Wireframe Build**：点云 / 技术线框 / 白模与真实实体交织，适合工业科普。
- **Voxel Flip**：密集方片、三角碎片翻转吸附，几何建造感更强。
- **Scan Reveal**：一道富有层次的空间构建波划过大型场景，适合快速转场。

## 使用场景与体验

例如：导入一个完整的极客桌面、数据中心、城市街道或手机拆解模型，用户只需要设定重建起点、挑选预设并调整动画，即可做出一个有质感的镜头。

希望有**中文、直观、可视化**的控制界面：导入场景、选择对象与起点、调整风格与动画、拖动进度预览、设计运镜、保存配置、录制或输出素材。日后换模型也能复用，不需要每次重新开发特效。

## 什么样的结果才算好

**画面：**从空白到实体的过程具有真实的三维空间层次，几何构建细节丰富，重建节奏自然且有冲击力，最终画面能达到高完成度 Motion Design 的质感。

**复用：**不局限于内置演示物体。复杂多物体场景中也能清楚看到构建过程，旋转摄影机后效果依然与三维世界一致。

**保真：**结束时原场景的结构和材质得到保留；任意时间点的预览与导出结果稳定。

**体验：**能以预设为起点快速做出成片，再按需要细调。为了更好的视觉效果和更顺手的使用体验，可以自主改良这里没有想到的细节。

具体技术方案和开发计划由开发者决定。
