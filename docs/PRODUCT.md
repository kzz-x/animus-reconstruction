# 产品与视觉说明

## 1. 一句话

让**任意导入的完整三维世界**从空白虚空中像被数字系统实时解码、建模、装配、渲染一样生成；既能独立制作视频，也能成为已有 Three.js 项目的通用转场。

## 2. 经典镜头的视觉阶段

- **0｜空白虚空**：无边界、白色/极浅灰场景，只有可选的保留角色、原点、稀疏格线。
- **1｜构建波前**：从用户指定的世界坐标向外扩散；地面先展开，随后建筑/设备表面逐步出现点云、网格和白模。
- **2｜几何拼合**：大量小型方片/三角片在波前附近翻转、短距离漂移、旋转并锁定到真实模型表面。碎片出现顺序与空间波前相关，不是全屏随机粒子。
- **3｜材质恢复**：白色/浅灰色形体被真实 PBR 贴图、表面属性、阴影与灯光逐区域取代；数字边缘伴随细密闪烁与微弱蓝白色同步扫描。
- **4｜完整世界**：全部残留视觉效果消失，原始场景完整稳定，后续可正常运镜和播放模型自带动画。

波前需要空间厚度：**未触达=空白，构建带=点/线框/碎片/白模，已触达=原材质实体**。允许分层时间偏移，使地面、墙体、屋顶、远景有节奏地构建。

## 3. 四种预设（共用引擎）

1. **经典 Animus**：白色虚空，水平径向波前 + 高度延迟，点云、细白网格、白模、翻转碎片、真实材质。默认首选。
2. **Wireframe Build**：点云 → 精密线框/技术插画 → 中性实体 → 原材质，可切换黑底/暖白底。
3. **Voxel Flip**：可控密度的方片/三角片沿表面翻转吸附并归位，适合产品近景；强调真实几何细节，避免廉价全屏随机像素。
4. **Scan Reveal**：球形/水平/路径扫描，短构建带、高完成度材质揭示，适合大场景快速转场。

每个预设由统一参数及各效果通道的开关/权重组合而成，可保存为 JSON。

## 4. 用户工作流

**导入**：GLB 为最高优先级；支持 GLTF 及关联纹理、嵌入已有 Three.js `Object3D`。识别层级、位置、尺寸、材质、灯光和模型动画；默认自动构图，但不自动破坏场景原始比例或层级。

**指定原点**：视口拾取点 / 选物体中心 / 手动 XYZ / 绑定某个移动物体。可以排除指定物体，例如保留人物，以人物脚下为波前起点。

**编辑**：中文「差点控件」：导入与场景、重建原点/范围、波前、构建形态、数字碎片、材质恢复、摄影机、时间轴与导出。高频控制项默认展开，更多参数折叠。

**播放**：进度滑杆、播放/暂停、定长（默认 6–8 秒可调）、循环、前后逐帧、从任意帧精确定位。相同时间点多次预览应得到相同结果。

**运镜**：Orbit 自由查看；摄像机位置/目标点/焦距关键帧；支持从全景推进到重建局部并顺滑转到成品视角。后续可增加焦点跟随、景深和轨迹预设。

**输出**：录制 WebM、逐帧 PNG（方便 AE/PR 合成）、项目设置 JSON、预设 JSON；优先保证固定时刻渲染一致性。可单独嵌入已有 Three.js 工作流。

## 5. 最低验收

- 不是仅对一张图片或单个 mesh 做 dissolve：同一预设对含**地板+分离零件/建筑+多种原材质**的完整场景生效。
- 可以在模型周围转动摄影机，重建边界始终锁在三维世界表面上，不随屏幕漂移。
- `progress=0` 真实内容隐藏，`progress=1` 与无预设原场景视觉一致；反复来回拖动无闪烁、遗漏或永久材质污染。
- 过渡中能明显区分空白、点/线构建、白模、碎片拼合、真实材质五类状态。
- 几何碎片依附模型表面，跟随重建位置、法线与模型变换；密度可调且不强制真实网格切割。
- 运行时可切换场景和预设，旧资源能正确释放，不出现材质丢失、累积重影或明显持续内存增长。

## 6. 兼容边界

优先支持标准 GLTF PBR 的静态 Mesh、多材质、复杂层级。SkinnedMesh、MorphTarget、透明/透射、Instancing、非标准自定义 Shader、GLTF 模型动画逐级拓展；特殊材质需明确显示采用兼容通道或替代渲染，不能悄悄将最终材质永久替换为白模。`GLTF` 多文件资源需有明确的文件映射策略，不能把 `GLTF` 说成等同于单文件 `GLB`。
